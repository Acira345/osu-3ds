# osu!3DS 🌸

**osu!3DS** — это полноценный нативный порт игры **osu!** для семейства консолей **Nintendo 3DS, 2DS, New 3DS и New 2DS**. Проект написан «с нуля» на языке C++20 с использованием библиотек `libctru`, `Citro2D` и `Citro3D`.

Игра отлично оптимизирована: она работает со стабильной частотой **60 кадров в секунду (FPS)** даже на оригинальной модели консоли (Old 3DS). В ней задействованы все особенности системы: два экрана, сенсорное управление стилусом и **настоящий стереоскопический 3D-эффект**.
